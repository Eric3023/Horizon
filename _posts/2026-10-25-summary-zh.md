## [HTTP2Shell 漏洞影响众多 HTTP 库](https://www.aikido.dev/blog/python-packages-vulnerable-node2shell-brotli-cve-2026-111497) ⭐️ 8.0/10

HTTP2Shell 漏洞（之前称为 Node2Shell）影响众多 HTTP 库和应用程序，可能导致远程代码执行。 这个漏洞非常重要，因为它影响了广泛的 HTTP 库和应用程序，对许多系统构成安全风险，可能导致广泛的利用。 该漏洞由不安全的 Brotli 解码器实现引起，影响解码 HTTP 上的 Brotli 的库，包括 Python、C++、curl、Bun 和 Envoy。

**背景**: HTTP2Shell 是一种安全漏洞，攻击者可以通过利用 Brotli 压缩库中的漏洞，在目标系统上执行任意代码。该漏洞影响使用 Brotli 压缩算法的 HTTP 响应的应用程序。
